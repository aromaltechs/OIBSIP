# Srinivasa Ramanujan Tribute Page

A responsive tribute webpage dedicated to Srinivasa Ramanujan, the renowned Indian mathematician whose contributions continue to influence the world of mathematics.

## About the Project

This project presents an overview of Ramanujan's life, mathematical contributions, and lasting legacy through a simple, structured webpage.

## Features

* Introduction to Srinivasa Ramanujan
* Overview of his life and mathematical work
* Highlights of his mathematical legacy
* Timeline of important events
* Responsive layout for desktop and mobile devices

## Technologies Used

* HTML5
* CSS3

## How to Run

1. Download or clone this repository.
2. Open the `WebDev-L2-TributePage` folder.
3. Open `index.html` in a web browser.

No additional dependencies or installation steps are required.
