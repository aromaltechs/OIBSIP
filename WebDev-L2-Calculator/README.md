# Calculator

A responsive calculator web application built using HTML5, CSS3, and vanilla JavaScript as part of the Oasis Infobyte Web Development Level 2 internship task.

## Features

* Basic arithmetic operations: addition, subtraction, multiplication, and division
* Decimal number support
* Operator chaining
* Clear (`AC`) functionality
* Backspace functionality
* Division-by-zero handling
* Responsive layout
* Interactive button effects
* Built without `eval()`
* Uses JavaScript `addEventListener()` for user interactions

## Technologies Used

* HTML5
* CSS3
* JavaScript

## Project Structure

```text
WebDev-L2-Calculator/
```

## How to Run

1. Clone or download this repository.
2. Open the `WebDev-L2-Calculator` folder.
3. Open `index.html` in a web browser.

You can also use the VS Code Live Server extension to run the project locally.
