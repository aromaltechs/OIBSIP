# OIBSIP

**Oasis Infobyte Internship Projects**

A collection of web development projects completed as part of the **Oasis Infobyte AICTE Student Internship Program — Web Development and Designing, Level 2**.

* **Intern:** Aromal Suresh
* **Organization:** Oasis Infobyte
* **Track:** Web Development and Designing
* **Level:** Level 2

## Projects Included

### Task 1 — Calculator Web Application

A responsive browser-based calculator supporting basic arithmetic operations, decimal numbers, operator chaining, and standard mathematical precedence.

* **Technologies:** HTML5, CSS3, Vanilla JavaScript
* [Source Code](WebDev-L2-Calculator/)
* [Live Demo](https://aromaltechs.github.io/OIBSIP/WebDev-L2-Calculator/)
* [Demo Video](https://youtu.be/Mis6_G93PgQ)

### Task 2 — Tribute Page

A responsive tribute webpage celebrating Srinivasa Ramanujan and his contributions to mathematics.

* **Technologies:** HTML5, CSS3
* [Source Code](WebDev-L2-TributePage/)
* [Live Demo](https://aromaltechs.github.io/OIBSIP/WebDev-L2-TributePage/)
* [Demo Video](https://youtu.be/oMqEnGRcOec)

### Task 3 — To-Do Web App

A responsive task management application that allows users to create, edit, complete, and delete tasks, with data persistence using browser Local Storage.

* **Technologies:** HTML5, CSS3, JavaScript, Browser Local Storage, Font Awesome
* [Source Code](WebDev-L2-ToDoApp/)
* [Live Demo](https://aromaltechs.github.io/OIBSIP/WebDev-L2-ToDoApp/)
* [Demo Video](https://youtu.be/Wwy2oWJNJ1I)

### Task 4 — Login Authentication System

A browser-based authentication application featuring user registration, password validation, login authentication, a protected dashboard, and session management.

* **Technologies:** HTML5, CSS3, JavaScript, Web Crypto API, Browser Local Storage, Browser Session Storage
* [Source Code](WebDev-L2-LoginAuth/)
* [Live Demo](https://aromaltechs.github.io/OIBSIP/WebDev-L2-LoginAuth/)
* [Demo Video](https://youtu.be/mNeDNYjZCMU)

## How to Run

1. Clone the repository:

   ```bash
   git clone https://github.com/aromaltechs/OIBSIP.git
   ```

2. Open the repository folder in Visual Studio Code.

3. Navigate to any project folder.

4. Open its `index.html` file in a browser.

Alternatively, use the Live Server extension in Visual Studio Code for local development.
