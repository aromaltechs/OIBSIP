# To-Do Web App

A simple and responsive To-Do Web App built using HTML, CSS, and JavaScript. It helps users organize their daily tasks by managing pending and completed activities.

## Features

* Add new tasks
* Edit existing tasks
* Mark tasks as completed
* Move completed tasks back to pending
* Delete tasks
* Display separate pending and completed task lists
* Automatically update task counts
* Display messages when task lists are empty
* Save tasks using browser Local Storage
* Responsive design for desktop and mobile devices

## Technologies Used

* HTML5
* CSS3
* JavaScript
* Browser Local Storage

## How to Run

1. Clone or download this repository.
2. Open the `WebDev-L2-ToDoApp` folder.
3. Open `index.html` in a web browser.

Alternatively, use the Live Server extension in Visual Studio Code.
